# Nura Headphones Landing Page

A landing page for a made-up headphone brand, built to practise Bootstrap 5 and turning a design into a responsive page.

## What is on the page

- Navbar that collapses on small screens
- Hero section
- Four feature cards (Bootstrap grid)
- Product section with a colour picker that swaps the image
- Specs table
- Customer reviews (sample text)
- FAQ (Bootstrap accordion)
- Email form with validation

## How to run

Open `index.html` in a browser. Bootstrap loads from a CDN, so you need an internet connection.

## Images

Put the pictures in the `images/` folder. File names are in the image guide. If a picture is missing the page still works.

Built with HTML5, CSS3, Bootstrap 5 and a little JavaScript.
